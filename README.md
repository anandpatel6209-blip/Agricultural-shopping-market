# 🌾 Agricultural-shopping-market

A responsive agricultural shopping platform built for farmers — featuring crop and spray/product browsing, bilingual Hindi-English support, shopping cart functionality, and a dedicated admin dashboard for managing orders, products, inventory, farmers, payments, and more.

## ✨ Features

### Farmer-facing
- 📱 **OTP-based mobile login** with name entry
- 🌾 **Crop browsing** — explore available crops
- 💊 **Spray / product browsing** — view and select agricultural products
- 🛒 **Shopping cart** — add products, review, and checkout
- 🌐 **Bilingual support** — toggle between Hindi and English instantly
- 🌙 **Light / Dark theme** toggle
- 📍 **Store location** with Google Maps integration
- 🚚 **Delivery tracking** flow

### Admin dashboard
- 📦 **Order management** — view, update, and track customer orders
- 🛍️ **Product management** — add, edit, and remove products
- 📊 **Inventory management** — track stock levels
- 👨‍🌾 **Farmer management** — view and manage registered farmers
- 💳 **Payment tracking** — monitor transactions and payment status
